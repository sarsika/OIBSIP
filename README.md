## Task Details

### Task 2 — Number Guessing Game
A GUI-based number guessing game built with Java Swing. Users select a difficulty level, and the system generates a random number within the corresponding range. The player guesses until correct or until attempts run out, with live feedback and a round summary.
- **Tech Stack:** Java, Swing
- **Folder:** `Java-Task2-NumberGuessingGame/`

### Task 5 — Digital Library Management System
A web-based library management system with separate Admin and User roles. Supports book cataloguing, issuing/returns, fine tracking, and user management.
- **Tech Stack:** Java (Spring Boot), MySQL, HTML/CSS/JavaScript
- **Folder:** `digital-library-management-system/`
